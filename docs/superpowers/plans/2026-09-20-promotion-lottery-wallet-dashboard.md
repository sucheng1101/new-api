# 推广、抽奖、钱包账务与新版数据看板实施计划

**目标：** 按已确认 Spec 分阶段实现三账户钱包、两级推广、管理员退款、每日抽奖和新版数据看板，并保证账务幂等、来源可追溯及 SQLite/MySQL/PostgreSQL 兼容。

**架构约束：** 保持 Router -> Controller -> Service -> Model 分层。余额事实以数据库、不可变流水和现金批次为准，Redis 只缓存总可用额度。计费表达式仍决定最终消费 quota，钱包层只负责按赠送优先、现金 FIFO 分摊该 quota，不改变表达式计算和冻结快照。

**技术栈：** Go 1.22、Gin、GORM v2、React 18、Vite、Semi Design、Bun。
